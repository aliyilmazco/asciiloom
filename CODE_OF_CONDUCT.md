# Code of Conduct

## Our standard

We want README ASCII Studio to be a welcoming, constructive project. Participants are expected to communicate with respect, assume good faith, explain technical disagreements clearly, and make room for people with different backgrounds and experience levels.

## Expected behavior

- Use inclusive language and focus feedback on the work.
- Ask questions before assuming intent.
- Accept correction and revise factual or technical mistakes.
- Protect private information and do not publish credentials, personal data, or private reports.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, unwanted sexualized conduct, deliberate disruption, and public disclosure of private security reports are not acceptable.

## Enforcement

For conduct concerns, use a private contact method published on the [`aliyilmazco` GitHub profile](https://github.com/aliyilmazco) rather than opening a public issue. Security concerns should follow [`SECURITY.md`](https://github.com/aliyilmazco/ascii-art-for-md/blob/main/SECURITY.md). Maintainers may remove comments, restrict participation, or close contributions when necessary to keep the project safe and constructive.
